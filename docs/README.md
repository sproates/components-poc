# Documentation

Start with the component catalogue to see what's included, or the component authoring guide to extend the PoC.

- [Component catalogue](component-catalog.md): available components, their APIs and demonstration scenarios.
- [Creating a component](creating-a-component.md): add a reusable component, Storybook stories, functional tests and performance checks.
- [How memory testing works](how-memory-testing-works.md): measurement cycles, cleanup checks, budgets and limitations.
- [Adopting story tests](adopting-story-tests.md): integrate Storybook's Vitest addon into an existing repository and CI workflow.
- [Adopting runtime checks](adopting-runtime-checks.md): reuse the rendering and cleanup harness, register scenarios and establish performance budgets.

The adoption guides are generic integration recipes. Verify them against the destination repository's configuration and dependencies.
